## 分段机制说明

### 当前分段逻辑

NLP智能分段会把一条或多条字幕合并成一个表达完整的补画面镜头。核心目标不是机械按时间切，而是尽量让每个镜头对应一个可用于搜索素材的完整意思。

```python
def _nlp_segment_subtitles(subtitles, data):
    """
    分段流程：
    1. 先规范化字幕时间和文本
    2. 连续合并字幕，维护当前段落的关键词和主题
    3. 在完整句子、明显停顿、主题变化或最大时长附近关闭段落
    4. 对过短段落做二次合并，避免碎片化镜头
    """
```

### 分段关闭条件

按优先级综合判断：

1. **达到最大时长**：超过 `max_shot_duration` 后进入兜底关闭，但会尽量避开明显未说完的短语。
2. **句子完整**：检测到句号、问号、感叹号、分号等句末符号，并且下一句不是“然后、所以、但是”等承接词。
3. **停顿明显**：两条字幕之间间隔较长，且当前表达完整。
4. **主题变化**：关键词明显变化，并且当前句子已经完整。
5. **过短回并**：生成后发现某段太短，会优先和前一段合并。

### 分段参数

| 参数 | 默认值 | 说明 | 影响 |
|-----|--------|------|------|
| `min_shot_duration` | 3.0秒 | 最小镜头时长 | 越大→镜头越少、越长 |
| `max_shot_duration` | 8.0秒 | 最大镜头时长 | 越小→镜头越多、越短 |
| `prefer_sentence_boundary` | true | 优先在句子边界分段 | false→更激进的主题分段 |

### 句子边界检测

检测以下标点符号：
```
中文：。！？；
英文：. ! ? ;
```

### 主题变化检测

根据当前段落关键词和下一条字幕关键词判断：
```python
if 当前段落关键词 和 下一条字幕关键词 基本没有重叠:
    认为主题变化
```

主题变化只作为辅助条件。默认仍优先保证当前表达完整，避免为了追求“主题切换”把一句话切断。

## 调整分段的方法

### 方法1: 配置参数调整（推荐）✅

在生成补画面方案时传入配置参数。

#### 示例1: 生成更少、更长的镜头

```javascript
fetch('/api/broll/plan-task', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    project_id: 'xxx',
    min_shot_duration: 5.0,   // 提高最小时长
    max_shot_duration: 15.0,  // 提高最大时长
    prefer_sentence_boundary: true
  })
})
```

**效果**:
- 镜头数量减少
- 每个镜头更长
- 适合：慢节奏视频、纪录片

#### 示例2: 生成更多、更短的镜头

```javascript
fetch('/api/broll/plan-task', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    project_id: 'xxx',
    min_shot_duration: 2.0,   // 降低最小时长
    max_shot_duration: 6.0,   // 降低最大时长
    prefer_sentence_boundary: false  // 更激进分段
  })
})
```

**效果**:
- 镜头数量增加
- 每个镜头更短
- 适合：快节奏视频、短视频

#### 示例3: 严格按句子分段

```javascript
fetch('/api/broll/plan-task', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    project_id: 'xxx',
    min_shot_duration: 3.0,
    max_shot_duration: 12.0,
    prefer_sentence_boundary: true  // 优先句子边界
  })
})
```

**效果**:
- 保证句子完整性
- 不会在句子中间切断
- 适合：教学视频、演讲视频

### 方法2: 手动合并镜头 ✅

如果两个镜头分得太细，可以合并。

#### API

```
POST /api/broll/merge-shots
```

#### 请求参数

```json
{
  "project_id": "xxx",
  "shot_id1": "s001",  // 第一个镜头ID
  "shot_id2": "s002"   // 第二个镜头ID（必须相邻）
}
```

#### 返回

```json
{
  "code": 0,
  "msg": "镜头合并成功",
  "data": {
    "merged_shot": {
      "shot_id": "s001",
      "start": 0.0,
      "end": 8.5,
      "duration": 8.5,
      "subtitle_text": "今天我们来介绍 人工智能的发展历史",
      "subtitle_indices": [0, 1, 2, 3],
      "theme": "人工智能、介绍、发展、历史",
      "keywords": ["人工智能", "介绍", "发展", "历史"],
      "candidates": []
    },
    "total_shots": 9,
    "broll_session": {...}
  }
}
```

#### 效果

- 两个镜头合并为一个
- 字幕索引合并
- 关键词合并（去重）
- 主题更新
- 镜头自动重新编号

#### 返回

```json

  "data": {
    "shot1": {
      "shot_id": "s001",

      "end": 4.5,
      "duration": 4.5,
      "subtitle_indices": [0, 1],

    "shot2": {
```

#### 效果

- 一个镜头分割为两个

- 镜头自动重新编号

如果对整体分段不满意，可以调整参数后重新生成。

```javascript
// 1. 调整参数
const newConfig = {
  project_id: 'xxx',
  min_shot_duration: 4.0,  // 调整参数

.then(data => {

  // 等待任务完成后查看新的分段
```

## 素材搜索和替换

### 默认候选数量

每个镜头默认搜索 **1-3 个候选素材**：

- 有候选时自动选中评分最高的素材
- 用户可以在候选下拉框里切换替换素材
- 单个镜头可以点 `重搜`
- 多个镜头可以先勾选 `选中`，再点 `重搜选中`
- 点 `自动合成` 时会自动下载缺失的已选素材，再参与视频合成
- 已选素材下载失败时，会继续尝试同一镜头的其他候选素材

### 内容安全策略

素材搜索会尽量避开暴力、血腥和过度刺激的画面。系统会过滤标题、描述、来源等字段中包含以下倾向的候选：

```text
血腥、暴力、尸体、枪击、枪杀、砍杀、屠杀、爆炸、死亡、恐怖袭击
gore、bloody、blood、violence、kill、murder、dead、death、weapon、gun
```

说明：这是基于素材元数据的过滤，无法百分百识别所有画面内容。实际发布前仍建议人工快速检查候选素材。

### 新闻类素材倾向

当字幕包含政治、时政、外交、军事、国防、军队、会议、新闻、发布会等主题时，搜索会自动补充更适合新闻画面的关键词：

```text
news footage
press conference
government meeting
defense briefing
military parade
reporter
```

这样更容易搜到正常的时政、军事、发布会、会议、资料画面，而不是血腥冲突或影视化战争画面。

### 单个镜头重搜

```javascript
fetch('/api/broll/search-task', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    project_id: 'xxx',
    shot_id: 's003'
  })
})
```

### 多个镜头重搜

```javascript
fetch('/api/broll/search-task', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    project_id: 'xxx',
    shot_ids: ['s001', 's003', 's005']
  })
})
```

**效果**：
- 只替换指定镜头的候选素材
- 其他镜头保持不变
- 被锁定镜头如果被明确选中重搜，也会执行重搜
- 每个被重搜镜头仍最多保留 3 个候选素材

## API使用示例

### 完整工作流

```javascript
// 1. 生成补画面方案（带配置）
async function generateBrollPlan(projectId, config) {
  const response = await fetch('/api/broll/plan-task', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      project_id: projectId,
      min_shot_duration: config.minDuration || 3.0,
      max_shot_duration: config.maxDuration || 8.0,
      prefer_sentence_boundary: config.preferSentence !== false
    })
  });
  return response.json();
}

// 2. 搜索全部镜头素材
async function searchAllShots(projectId) {
  const response = await fetch('/api/broll/search-task', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      project_id: projectId
    })
  });
  return response.json();
}

// 3. 重搜一个或多个镜头
async function researchShots(projectId, shotIds) {
  const ids = Array.isArray(shotIds) ? shotIds : [shotIds];
  const response = await fetch('/api/broll/search-task', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      project_id: projectId,
      shot_ids: ids
    })
  });
  return response.json();
}

// 4. 合并两个镜头
async function mergeShots(projectId, shotId1, shotId2) {
  const response = await fetch('/api/broll/merge-shots', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      project_id: projectId,
      shot_id1: shotId1,
      shot_id2: shotId2
    })
  });
  return response.json();
}

// 5. 分割镜头
async function splitShot(projectId, shotId, splitTime) {
  const response = await fetch('/api/broll/split-shot', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      project_id: projectId,
      shot_id: shotId,
      split_time: splitTime
    })
  });
  return response.json();
}

// 使用示例
(async () => {
  // 生成方案
  await generateBrollPlan('project123', {
    minDuration: 4.0,
    maxDuration: 8.0,
    preferSentence: true
  });

  // 搜索全部镜头素材
  await searchAllShots('project123');

  // 同时重搜多个镜头
  await researchShots('project123', ['s001', 's003']);

  // 合并镜头s001和s002
  await mergeShots('project123', 's001', 's002');

  // 在5.5秒处分割镜头s003
  await splitShot('project123', 's003', 5.5);
})();
```

## 常见场景和解决方案

### 场景1: 镜头太多，切换太频繁

**问题**:
```
生成了20个镜头，每个2-3秒，切换太快
```

**解决方案**:

**方法A: 调整参数重新生成**
```javascript
{
  min_shot_duration: 5.0,   // 提高到5秒
  max_shot_duration: 15.0,  // 提高到15秒
  prefer_sentence_boundary: true
}
```

**方法B: 手动合并相邻镜头**
```javascript
// 合并s001和s002
await mergeShots('project123', 's001', 's002');
// 合并s003和s004
await mergeShots('project123', 's003', 's004');
```

---

### 场景2: 镜头太少，不够灵活

**问题**:
```
只生成了5个镜头，每个10-15秒，太长了
```

**解决方案**:

**方法A: 调整参数重新生成**
```javascript
{
  min_shot_duration: 2.0,   // 降低到2秒
  max_shot_duration: 6.0,   // 降低到6秒
  prefer_sentence_boundary: false  // 更激进分段
}
```

**方法B: 手动分割长镜头**
```javascript
// 在5秒处分割s001
await splitShot('project123', 's001', 5.0);
// 在8秒处分割s002
await splitShot('project123', 's002', 8.0);
```

---

### 场景3: 句子被切断

**问题**:
```
镜头1: "今天我们来介绍人工"
镜头2: "智能的发展历史"
```

**解决方案**:

**方法A: 启用句子边界优先**
```javascript
{
  prefer_sentence_boundary: true  // 确保启用
}
```

**方法B: 手动合并被切断的镜头**
```javascript
await mergeShots('project123', 's001', 's002');
```

---

### 场景4: 主题变化不明显

**问题**:
```
整段视频都在讲同一个主题，但被分成了很多镜头
```

**解决方案**:

**调整参数，提高最小时长**
```javascript
{
  min_shot_duration: 6.0,   // 提高最小时长
  max_shot_duration: 20.0,  // 提高最大时长
  prefer_sentence_boundary: true
}
```

---

### 场景5: 需要精确控制某个镜头

**问题**:
```
镜头s003的分段不理想，想精确调整
```

**解决方案**:

**使用分割和合并组合**
```javascript
// 1. 先分割
await splitShot('project123', 's003', 7.5);
// 现在s003变成了s003和s004

// 2. 如果s004还是太长，再分割
await splitShot('project123', 's004', 10.0);

// 3. 如果s003太短，和前一个合并
await mergeShots('project123', 's002', 's003');
```

---

### 场景6: 多个镜头素材不合适

**问题**:
```
s001、s003、s005 的候选素材不贴合，想一次性重新搜索
```

**解决方案**:

**页面操作**：
- 勾选对应镜头的 `选中`
- 点击工具栏里的 `重搜选中`

**API 调用**：
```javascript
await researchShots('project123', ['s001', 's003', 's005']);
```

---

### 场景7: 搜到了血腥或暴力倾向素材

**问题**:
```
军事新闻主题搜到了枪击、爆炸、血腥画面
```

**解决方案**:

- 先使用 `重搜` 或 `重搜选中` 换一批候选
- 优先选择发布会、记者、政府会议、军队队列、装备展示等中性新闻画面
- 发布前人工检查候选原页和预览，避免元数据漏判

## 最佳实践

### 1. 先用默认参数生成

```javascript
// 第一次生成，使用默认参数
await generateBrollPlan('project123', {});
```

**查看结果**:
- 镜头数量是否合理
- 镜头时长是否合适
- 句子是否完整

### 2. 根据视频类型调整

**快节奏视频**（短视频、广告）:
```javascript
{
  min_shot_duration: 2.0,
  max_shot_duration: 5.0,
  prefer_sentence_boundary: false
}
```

**慢节奏视频**（纪录片、教学）:
```javascript
{
  min_shot_duration: 5.0,
  max_shot_duration: 15.0,
  prefer_sentence_boundary: true
}
```

**中等节奏视频**（新闻、访谈）:
```javascript
{
  min_shot_duration: 3.0,
  max_shot_duration: 10.0,
  prefer_sentence_boundary: true
}
```

### 3. 局部调整优于全局重生成

如果只有少数几个镜头不满意：
- ✅ 分段不满意时使用合并/分割API调整
- ✅ 素材不满意时使用单个 `重搜` 或批量 `重搜选中`
- ❌ 不要重新生成整个方案

### 4. 素材先看候选，再决定是否重搜

每个镜头默认有 1-3 个候选素材。建议先在候选下拉框切换查看，如果多个候选都不合适，再重搜当前镜头或批量重搜多个镜头。

### 5. 保存满意的配置

记录对不同类型视频有效的配置：

```javascript
const configs = {

    max_shot_duration: 5.0,

    min_shot_duration: 5.0,
    max_shot_duration: 15.0,
    prefer_sentence_boundary: true
  },

    min_shot_duration: 4.0,
    max_shot_duration: 12.0,
    prefer_sentence_boundary: true
  }

// 使用
await generateBrollPlan('project123', configs.shortVideo);
```

## 故障排除

### 问题: 合并镜头失败

**错误**: "只能合并相邻的镜头"

**原因**: 两个镜头不相邻

**解决**: 确保shot_id是连续的（s001和s002，不能是s001和s003）

---

### 问题: 分割镜头失败

**错误**: "分割时间必须在镜头范围内"

**原因**: split_time不在镜头的start和end之间

**解决**:
```javascript
// 检查镜头时间范围
const shot = session.shots.find(s => s.shot_id === 's001');
console.log(`镜头范围: ${shot.start} - ${shot.end}`);

// 确保split_time在范围内
const splitTime = (shot.start + shot.end) / 2;  // 使用中点
await splitShot(projectId, 's001', splitTime);
```

---

### 问题: 参数不生效

**原因**: 参数拼写错误或类型错误

**解决**:
```javascript
// ✅ 正确
{
  min_shot_duration: 5.0,  // 数字类型
  max_shot_duration: 8.0,
  prefer_sentence_boundary: true  // 布尔类型
}

// ❌ 错误
{
  minShotDuration: 5.0,  // 驼峰命名错误
  max_shot_duration: "8.0",  // 字符串类型错误
  prefer_sentence_boundary: "true"  // 字符串类型错误
}
```

## 总结

### 调整分段和素材的五种方式

1. **配置参数** - 生成时调整（推荐首选）
2. **合并镜头** - 镜头太多时使用
3. **分割镜头** - 镜头太长时使用
4. **单镜头重搜** - 某个镜头素材不合适时使用
5. **批量重搜** - 多个镜头素材不合适时使用

### 推荐流程

```
1. 使用默认参数生成
   ↓
2. 查看分段结果
   ↓
3. 如果整体不满意 → 调整参数重新生成
   如果局部不满意 → 使用合并/分割API
   ↓
4. 搜索素材，每个镜头默认 1-3 个候选
   ↓
5. 如果素材不合适 → 单个重搜或批量重搜
   ↓
6. 自动合成，系统自动下载缺失的已选素材
   ↓
7. 完成
```
