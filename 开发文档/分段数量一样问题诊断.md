# 分段数量总是一样的问题诊断

**问题**: 同一个视频，修改分段时间后，生成的分段数量总是一样

---

## 🔍 可能的原因

### 原因1: 字幕没有句子结束标点 ⭐⭐⭐⭐⭐

**最常见的原因！**

**症状**:
```
字幕1: 今天我们来介绍
字幕2: 人工智能的发展
字幕3: 从1950年代开始
```

**问题**: 没有句子结束标点（。！？），导致：
- 启用"优先句子边界"时，永远不会在句子边界分段
- 只能靠"超过最大时长"强制分段
- 不同配置可能生成相同数量的镜头

**解决方法**:
1. **禁用"优先句子边界"** ✅
   - 取消勾选"优先在句子边界分段"
   - 这样会更激进地分段

2. **调整最大时长** ✅
   - 快节奏: max=5秒
   - 慢节奏: max=15秒
   - 通过最大时长强制分段

---

### 原因2: 主题单一，关键词重叠度高 ⭐⭐⭐⭐

**症状**:
```
字幕1: 人工智能技术
字幕2: 人工智能发展
字幕3: 人工智能应用
```

**问题**: 所有字幕都在讲同一个主题
- 关键词重叠度 > 30%
- 不会触发主题变化分段
- 只能靠时长和句子边界分段

**解决方法**:
1. **降低最大时长** ✅
   - 从10秒降到5秒
   - 强制更频繁地分段

2. **禁用"优先句子边界"** ✅
   - 让系统更激进地分段

---

### 原因3: 字幕总时长太短 ⭐⭐⭐

**症状**:
```
总时长: 10秒
字幕数: 5条
```

**问题**: 字幕太短，无论什么配置都只能分成1-2个镜头

**解决方法**:
- 使用更长的视频测试
- 至少30秒以上的字幕

---

### 原因4: 配置参数没有真正传递 ⭐⭐

**症状**: 后端日志显示配置总是默认值

**检查方法**:
```bash
# 查看后端日志
tail -f logs/app.log | grep "分段配置"
```

**应该看到**:
```
分段配置: min_duration=2.0, max_duration=5.0, prefer_sentence_boundary=False
```

**如果总是显示**:
```
分段配置: min_duration=3.0, max_duration=10.0, prefer_sentence_boundary=True
```

**说明**: 配置没有传递，需要清除浏览器缓存

---

## 🎯 快速诊断步骤

### 步骤1: 检查字幕是否有标点

**在浏览器控制台执行**:
```javascript
// 检查字幕标点
const subtitles = state.subtitles || [];
const withPunctuation = subtitles.filter(s => /[。！？\.!?;；]$/.test(s.text));
console.log(`总字幕数: ${subtitles.length}`);
console.log(`有标点的: ${withPunctuation.length}`);
console.log(`标点比例: ${(withPunctuation.length / subtitles.length * 100).toFixed(1)}%`);

// 显示前5条字幕
console.log('\n前5条字幕:');
subtitles.slice(0, 5).forEach((s, i) => {
  console.log(`${i+1}. ${s.text}`);
});
```

**结果分析**:
- 标点比例 < 20% → **这就是问题！**
- 标点比例 > 50% → 标点正常

## 💡 解决方案

### 方案1: 禁用"优先句子边界" (推荐)

**适用于**: 字幕没有标点的情况

**操作**:
1. 展开配置面板
2. **取消勾选** "优先在句子边界分段"
3. 设置合适的时长:
   - 快节奏: min=2.0, max=5.0
   - 默认: min=3.0, max=8.0
   - 慢节奏: min=5.0, max=12.0
4. 点击"应用配置并重新分段"

**效果**: 系统会更激进地分段，不依赖标点符号

---

### 方案2: 调整最大时长

**适用于**: 主题单一的情况

**操作**:
1. 快节奏: max=4.0秒
2. 默认: max=8.0秒
3. 慢节奏: max=15.0秒

**效果**: 通过最大时长强制分段

---

### 方案3: 修改分段算法 (高级)

**如果以上方案都不行**，可以修改算法：

**修改文件**: `backend/services/broll_service.py`

**找到第643行**:
```python
elif is_sentence_end and duration >= min_duration:
    # 句子结束且已达到最小时长
    should_split = True
```

**修改为**:
```python
elif is_sentence_end and duration >= min_duration:
    # 句子结束且已达到最小时长
    should_split = True
elif not prefer_sentence_boundary and duration >= min_duration * 1.5:
    # 非句子边界模式下，达到1.5倍最小时长也分段
    should_split = True
```

**效果**: 即使没有句子结束和主题变化，达到1.5倍最小时长也会分段

## 📊 测试案例

### 案例1: 无标点字幕

**字幕**:
```
1. 今天我们来介绍
2. 人工智能的发展
3. 从1950年代开始
4. 科学家们就在研究
```

**默认配置 (min=3, max=10, prefer=true)**:
- 结果: 1个镜头 (0-8秒)
- 原因: 没有标点，没有主题变化，未超过最大时长

**禁用句子边界 (min=3, max=10, prefer=false)**:
- 结果: 1个镜头 (0-8秒)
- 原因: 没有主题变化，未超过最大时长

**降低最大时长 (min=2, max=5, prefer=false)**:
- 结果: 2个镜头 (0-4秒, 4-8秒)
- 原因: 超过最大时长，强制分段 ✅

---

### 案例2: 有标点字幕

**字幕**:

1. 今天我们来介绍
2. 人工智能的发展历史。

**默认配置 (min=3, max=10, prefer=true)**:
- 结果: 2个镜头
- 分段点: 字幕2结束（有标点）✅

**快节奏 (min=2, max=5, prefer=false)**:
- 结果: 2个镜头
- 分段点: 超过最大时长 ✅

## 🎯 最终建议

**对于大多数视频**:

**推荐配置**:
```
min_shot_duration: 2.5
max_shot_duration: 8.0
prefer_sentence_boundary: false  ← 关键！
```

**为什么**:
- 不依赖标点符号
- 更灵活的分段
- 适用于各种字幕

**如果字幕有完整标点**:
```
min_shot_duration: 3.0
max_shot_duration: 10.0
prefer_sentence_boundary: true
```
