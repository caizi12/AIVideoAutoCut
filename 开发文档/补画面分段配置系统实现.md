**实施日期**: 2026-05-28
**版本**: v2.0

---

## 🎯 功能概述

实现了一个灵活的分段配置系统，支持：

1. **配置模板** - 预设4种模板（默认、快节奏、慢节奏、中等节奏）
2. **项目级配置** - 每个项目独立配置
3. **实时调整** - 在页面上直接修改配置
4. **应用配置** - 修改后立即重新分段
5. **自定义检测** - 自动检测当前配置类型

## 🔧 技术实现

### 1. 配置模板定义

```javascript
const brollConfigTemplates = {
    default: {
        name: '默认',
        min_shot_duration: 3.0,
        max_shot_duration: 10.0,
        prefer_sentence_boundary: true
    },
    fast: {
        name: '快节奏',
        min_shot_duration: 2.0,
        max_shot_duration: 5.0,
        prefer_sentence_boundary: false
    },
    slow: {
        name: '慢节奏',
        min_shot_duration: 5.0,
        max_shot_duration: 15.0,
        prefer_sentence_boundary: true
    },
    medium: {
        name: '中等节奏',
        min_shot_duration: 3.5,
        max_shot_duration: 8.0,
        prefer_sentence_boundary: true
    },
    custom: {
        name: '自定义',
        min_shot_duration: 3.0,
        max_shot_duration: 10.0,
        prefer_sentence_boundary: true
    }
};
```

---

### 2. 获取当前配置

```javascript
function getBrollConfig() {
    return {
        min_shot_duration: parseFloat(els.brollMinDuration.value) || 3.0,
        max_shot_duration: parseFloat(els.brollMaxDuration.value) || 10.0,
        prefer_sentence_boundary: els.brollPreferSentence.checked
    };
}
```

---

### 3. 应用配置模板

```javascript
function applyBrollTemplate(templateName) {
    const template = brollConfigTemplates[templateName];
    if (!template) return;

    // 更新输入框
    els.brollMinDuration.value = template.min_shot_duration;
    els.brollMaxDuration.value = template.max_shot_duration;
    els.brollPreferSentence.checked = template.prefer_sentence_boundary;

    // 更新按钮状态
    document.querySelectorAll('.broll-template-btn').forEach(btn => {
        btn.classList.toggle('active', btn.dataset.template === templateName);
    });
}
```

---

### 4. 自动检测配置类型

```javascript
function detectCustomConfig() {
    const current = getBrollConfig();

    // 遍历所有模板
    for (const [key, template] of Object.entries(brollConfigTemplates)) {
        if (key === 'custom') continue;

        // 检查是否匹配
        if (current.min_shot_duration === template.min_shot_duration &&
            current.max_shot_duration === template.max_shot_duration &&
            current.prefer_sentence_boundary === template.prefer_sentence_boundary) {
            return key;
        }
    }

    return 'custom';
}
```

---

### 5. 发送配置到后端

```javascript
async function createBrollTask(url) {
    const config = getBrollConfig();

    const res = await apiJson(url, {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({
            project_id: state.projectId,
            source_video_path: state.serverVideoPath,
            subtitles: state.subtitles,
            style: state.style,
            aspect_ratio: els.brollAspectRatio.value,
            subtitle_mode: els.brollSubtitleMode.value,
            providers: ['wikimedia', 'internet_archive', 'nasa', 'pexels', 'pixabay'],
            // 分段配置参数
            min_shot_duration: config.min_shot_duration,
            max_shot_duration: config.max_shot_duration,
            prefer_sentence_boundary: config.prefer_sentence_boundary
        })
    });

    return res.data.task_id;
}
```

## 📊 配置参数说明

### min_shot_duration（最小镜头时长）

**范围**: 1-30秒
**默认**: 3.0秒

**效果**:
- ⬆️ 增大 → 镜头更少、更长
- ⬇️ 减小 → 镜头更多、更短

**建议值**:
- 快节奏视频: 2.0秒
- 中等节奏: 3.0-4.0秒
- 慢节奏视频: 5.0秒以上

---

### max_shot_duration（最大镜头时长）

**范围**: 3-60秒
**默认**: 10.0秒

**效果**:
- ⬆️ 增大 → 允许更长的镜头
- ⬇️ 减小 → 强制分割长镜头

**建议值**:
- 快节奏视频: 5.0秒
- 中等节奏: 8.0-10.0秒
- 慢节奏视频: 15.0秒以上

---

### prefer_sentence_boundary（优先句子边界）

**类型**: 布尔值
**默认**: true

**效果**:
- ✅ 启用 → 优先在句子结束处分段，保证句子完整性
- ❌ 禁用 → 更激进的主题分段，可能在句子中间切断

**建议**:
- 教学视频、演讲: ✅ 启用
- 快节奏短视频: ❌ 禁用
- 纪录片、访谈: ✅ 启用

## 🐛 故障排除

### 问题1: 配置不生效

**原因**: 没有点击"应用配置并重新分段"

**解决**: 修改配置后必须点击应用按钮

---

### 问题2: 最小时长大于最大时长

**错误**: "最小时长必须小于最大时长"

**解决**: 确保 min_shot_duration < max_shot_duration

---

### 问题3: 配置丢失

**原因**: 切换项目后配置重置

**解决**: 每个项目有独立配置，这是正常行为
