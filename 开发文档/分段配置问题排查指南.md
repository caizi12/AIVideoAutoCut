# 分段配置不生效问题排查指南

**问题**: 修改分段配置后，重新生成的分段和之前一样

**测试结果**: 后端分段逻辑正常工作 ✅

---

## 🔍 排查步骤

### 步骤1: 清除浏览器缓存

**问题**: 浏览器可能缓存了旧的JavaScript代码

**解决方法**:

1. **Chrome/Edge**:
   - 按 `Cmd+Shift+Delete` (Mac) 或 `Ctrl+Shift+Delete` (Windows)
   - 选择"缓存的图片和文件"
   - 点击"清除数据"

2. **或者强制刷新**:
   - 按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)

3. **或者硬性重新加载**:
   - 打开开发者工具 (F12)
   - 右键点击刷新按钮
   - 选择"清空缓存并硬性重新加载"

---

**预期结果**: 应该显示您设置的值

**测试3: 测试getBrollConfig函数**

        max_shot_duration: parseFloat(els.brollMaxDuration.value) || 10.0,

**预期结果**: 应该显示正确的配置对象

### 步骤3: 检查网络请求

**在浏览器开发者工具中**:

1. 打开 **Network** 标签
2. 点击"应用配置并重新分段"按钮
3. 查找 `/api/broll/plan-task` 请求
4. 点击该请求
5. 查看 **Payload** 或 **Request Payload**

**检查是否包含**:
```json
{
  "min_shot_duration": 5.0,
  "max_shot_duration": 15.0,
  "prefer_sentence_boundary": true
}
```

**如果没有这些字段** → 前端没有正确发送配置

**如果有这些字段** → 继续下一步

## 🐛 常见问题

### 问题1: 配置面板不显示

**症状**: 看不到"⚙️ 分段配置"面板

**原因**: HTML没有正确加载

**解决**:
1. 清除浏览器缓存
2. 强制刷新页面 (Cmd+Shift+R)
3. 检查HTML文件是否正确保存

---

### 问题2: 点击模板按钮没反应

**症状**: 点击"快节奏"等按钮，配置值不变

**原因**: JavaScript事件监听器没有绑定

**解决**:
1. 打开控制台，查看是否有JavaScript错误
2. 检查是否有语法错误
3. 确认页面完全加载后再点击

**测试**:
```javascript
// 在控制台执行
document.querySelectorAll('.broll-template-btn').forEach(btn => {
  console.log('模板按钮:', btn.dataset.template);
});
```

---

### 问题3: 配置发送了但分段没变

**症状**:
- 控制台显示: `发送分段配置: {min_shot_duration: 2, ...}`
- 后端日志显示: `分段配置: min_duration=2.0, ...`
- 但镜头数量没变

**可能原因**:

**A. 字幕内容导致**
- 如果字幕本身就很短（如总共只有10秒）
- 无论什么配置，都只能分成1-2个镜头

**B. 句子边界问题**
- 如果字幕没有句子结束标点（。！？）
- 优先句子边界模式可能无法正常分段

**C. 主题变化不明显**
- 如果所有字幕都在讲同一个主题
- 关键词重叠度很高，不会触发主题分段

**解决**:
1. 检查字幕内容
2. 尝试禁用"优先句子边界"
3. 调整最大时长，强制分段

---

### 问题4: 第一次生成就用了配置

**症状**: 第一次点击"生成补画面方案"就应用了配置

**说明**: 这是正常的！

- 第一次生成时，会读取配置面板的值
- 默认值是: min=3.0, max=10.0, prefer=true
- 如果您修改了配置，第一次生成就会使用新配置

## ✅ 验证配置是否生效

### 方法1: 查看镜头数量

**不同配置应该生成不同数量的镜头**:

| 配置 | 预期镜头数 |
|-----|-----------|
| 快节奏 (2-5秒) | 较多 |
| 默认 (3-10秒) | 中等 |
| 慢节奏 (5-15秒) | 较少 |

**示例**:
- 30秒字幕
- 快节奏: 6-8个镜头
- 默认: 3-5个镜头
- 慢节奏: 2-3个镜头

---

### 方法2: 查看镜头时长

**查看每个镜头的时长**:

```javascript
// 在控制台执行
const shots = state.brollSession?.shots || [];
shots.forEach((shot, i) => {
  console.log(`镜头${i+1}: ${shot.duration}秒`);
});
```

**验证**:
- 快节奏: 大部分镜头 2-5秒
- 默认: 大部分镜头 3-10秒
- 慢节奏: 大部分镜头 5-15秒

---

**记录第一次生成的结果**:

## 🎯 快速诊断

**在浏览器控制台执行以下代码**:

```javascript
// 完整诊断脚本
console.log('=== 分段配置诊断 ===');

// 1. 检查元素
const minEl = document.getElementById('brollMinDuration');
const maxEl = document.getElementById('brollMaxDuration');
const preferEl = document.getElementById('brollPreferSentence');

console.log('1. 配置元素存在:', {
  min: !!minEl,
  max: !!maxEl,
  prefer: !!preferEl
});

if (!minEl || !maxEl || !preferEl) {
  console.error('❌ 配置元素不存在，请刷新页面');
} else {
  // 2. 检查配置值
  console.log('2. 当前配置值:', {
    min: minEl.value,
    max: maxEl.value,
    prefer: preferEl.checked
  });

  // 3. 检查配置对象
  const config = {
    min_shot_duration: parseFloat(minEl.value) || 3.0,
    max_shot_duration: parseFloat(maxEl.value) || 10.0,
    prefer_sentence_boundary: preferEl.checked
  };
  console.log('3. 配置对象:', config);

  // 4. 检查当前镜头
  if (window.state && window.state.brollSession) {
    const shots = window.state.brollSession.shots || [];
    console.log('4. 当前镜头数:', shots.length);
    if (shots.length > 0) {
      console.log('   镜头时长:', shots.map(s => s.duration + 's').join(', '));
    }
  } else {
    console.log('4. 尚未生成镜头');
  }

  console.log('✅ 诊断完成');
}
```
