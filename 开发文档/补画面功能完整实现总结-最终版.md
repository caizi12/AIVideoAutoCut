## 🔧 核心技术实现

### 1. NLP智能分段

**分段条件**:
1. 超过最大时长（默认10秒）→ 强制分段
2. 句子结束 + 达到最小时长（默认3秒）→ 分段
3. 主题变化（关键词重叠度<30%）+ 达到最小时长 → 分段

**代码位置**: `backend/services/broll_service.py:_nlp_segment_subtitles()`

---

### 2. 多样化素材搜索

**策略**:
- 为每个查询词单独搜索
- 保证来自不同Provider
- 保证来自不同查询词
- 每个镜头1-3个候选

**代码位置**: `backend/services/broll_service.py:_search_candidates_for_shot()`

---

### 3. 智能评分算法

**评分维度**:
```python
score = 40  # 基础分
score += 时长匹配度(0-25分)
score += 分辨率质量(0-20分)
score += 横竖屏匹配(0-10分)
score += Provider优先级(0-10分)
score += 关键词匹配度(0-15分)  # 新增
```

**代码位置**: `backend/services/broll_service.py:_score_candidate()`

---

### 4. 配置模板系统

**4种预设模板**:
- 默认: 3-10秒，优先句子边界
- 快节奏: 2-5秒，激进分段
- 慢节奏: 5-15秒，优先句子边界
- 中等节奏: 3.5-8秒，优先句子边界

**代码位置**: `frontend/templates/subtitle_tool.html:brollConfigTemplates`

---

### 5. 手动调整API

**合并镜头**: `POST /api/broll/merge-shots`
```json
{
  "project_id": "xxx",
  "shot_id1": "s001",
  "shot_id2": "s002"
}
```

**分割镜头**: `POST /api/broll/split-shot`
```json
{
  "project_id": "xxx",
  "shot_id": "s001",
  "split_time": 5.5
}
```

**代码位置**: `backend/api/broll_api.py`, `backend/services/broll_service.py`

## 🎯 调整分段的方法

### 方法1: 配置模板（推荐）

**快节奏视频**:
```
选择"快节奏"模板
→ 2-5秒分段，激进分段
```

**慢节奏视频**:
```
选择"慢节奏"模板
→ 5-15秒分段，优先句子边界
```

**自定义**:
```
手动调整参数
→ 系统自动检测为"自定义"
```

---

### 方法2: 合并镜头

**场景**: 镜头太多，切换太频繁

```javascript
// 合并相邻镜头
await fetch('/api/broll/merge-shots', {
  method: 'POST',
  body: JSON.stringify({
    project_id: 'xxx',
    shot_id1: 's001',
    shot_id2: 's002'
  })
});
```

---

### 方法3: 分割镜头

**场景**: 镜头太长，需要分割

```javascript
// 在5.5秒处分割
await fetch('/api/broll/split-shot', {
  method: 'POST',
  body: JSON.stringify({
    project_id: 'xxx',
    shot_id: 's001',
    split_time: 5.5
  })
});
```

---

### 方法4: 重新搜索

**场景**: 对素材不满意

```javascript
// 重新搜索单个镜头
await fetch('/api/broll/research-shot', {
  method: 'POST',
  body: JSON.stringify({
    project_id: 'xxx',
    shot_id: 's001'
  })
});
```
