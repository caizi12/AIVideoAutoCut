## 🐛 如果有问题

### 问题: 分段数量还是一样

**检查网络请求**:
1. 打开控制台 (F12)
2. 切换到 Network 标签
3. 点击"应用配置并重新分段"
4. 找到 `/api/broll/plan-task` 请求
5. 查看 Request Payload

**应该包含**:
```json
{
  "min_shot_duration": 2.0,
  "max_shot_duration": 5.0,
  "prefer_sentence_boundary": false
}
```

**如果没有这些参数**:
- 清除缓存: Cmd+Shift+R
- 检查控制台是否有JavaScript错误

---

### 问题: 配置面板不显示

**检查**:
- 是否清除了缓存
- 控制台是否有JavaScript错误
- 页面是否完全加载

**解决**:
```
1. Cmd+Shift+R 强制刷新
2. 检查控制台错误
3. 如果有错误，截图发送
```
