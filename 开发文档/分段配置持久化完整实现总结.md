## 📋 问题概述

### 原始问题

1. **无标点字幕分段失效** - ASR生成的字幕没有标点符号，导致"优先句子边界"模式无法工作
2. **配置不持久化** - 重启后分段配置丢失，每次都需要重新设置
3. **分段数量总是一样** - 修改配置后，生成的分段数量没有变化

---

### 3. 前端恢复配置

**修改文件**: `frontend/templates/subtitle_tool.html`

**修改位置**: `applyBrollControls` 函数

**修改内容**:
```javascript
function applyBrollControls() {
    const session = state.brollSession || defaultBrollSession();
    els.brollAspectRatio.value = session.aspect_ratio || 'original';
    els.brollSubtitleMode.value = session.subtitle_mode || 'burned';

    // ✅ 恢复分段配置
    if (session.min_shot_duration !== undefined) {
        els.brollMinDuration.value = session.min_shot_duration;
    }
    if (session.max_shot_duration !== undefined) {
        els.brollMaxDuration.value = session.max_shot_duration;
    }
    if (session.prefer_sentence_boundary !== undefined) {
        els.brollPreferSentence.checked = session.prefer_sentence_boundary;
    }

    // ✅ 更新模板按钮状态
    const detected = detectCustomConfig();
    document.querySelectorAll('.broll-template-btn').forEach(btn => {
        btn.classList.toggle('active', btn.dataset.template === detected);
    });
}
```

### 4. 前端自动保存配置

**修改位置**: `saveBrollSessionSnapshot` 函数

**修改内容**:
```javascript
async function saveBrollSessionSnapshot(immediate = false) {
    if (!state.projectId || !state.brollSession) return;
    const run = async () => {
        try {
            state.brollSession.aspect_ratio = els.brollAspectRatio.value;
            state.brollSession.subtitle_mode = els.brollSubtitleMode.value;

            // ✅ 保存分段配置
            const config = getBrollConfig();
            state.brollSession.min_shot_duration = config.min_shot_duration;
            state.brollSession.max_shot_duration = config.max_shot_duration;
            state.brollSession.prefer_sentence_boundary = config.prefer_sentence_boundary;

            await apiJson(`/api/broll/session/${encodeURIComponent(state.projectId)}`, {
                method: 'POST',
                headers: {'Content-Type': 'application/json'},
                body: JSON.stringify(state.brollSession)
            });
        } catch (error) {
            console.warn('保存补画面工作区失败', error);
        }
    };
    // ...
}
```

**修改内容**:

```javascript
// ✅ 模板按钮点击自动保存
document.querySelectorAll('.broll-template-btn').forEach(btn => {
    btn.addEventListener('click', () => {
        applyBrollTemplate(btn.dataset.template);
        saveBrollSessionSnapshot(false);
    });
});

// ✅ 配置输入变化自动保存
[els.brollMinDuration, els.brollMaxDuration, els.brollPreferSentence].forEach(el => {
    el.addEventListener('change', () => {
        const detected = detectCustomConfig();
        document.querySelectorAll('.broll-template-btn').forEach(btn => {
            btn.classList.toggle('active', btn.dataset.template === detected);
        });
        saveBrollSessionSnapshot(false);
    });
});

// ✅ 应用配置按钮
els.brollApplyConfig.addEventListener('click', async () => {
    await saveBrollSessionSnapshot(true);  // 立即保存
    await runBrollTask('/api/broll/plan-task', ...);
});
```

## 🚀 使用指南

### 快速开始

1. **清除浏览器缓存**
   ```
   Cmd+Shift+R (Mac)
   Ctrl+Shift+R (Windows)
   ```

2. **上传视频并生成字幕**

3. **选择配置模板**
   - 快节奏: 2-5秒镜头

   - 慢节奏: 5-12秒镜头

4. **应用配置**
   - 点击"应用配置并重新分段"
   - 等待生成完成

5. **验证效果**
   - 查看镜头数量
   - 刷新页面验证配置保持
