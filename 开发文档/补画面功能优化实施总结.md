## 二、详细优化内容

### 2.1 NLP智能分段算法 ✅

**问题**: 原来的分段逻辑机械式按6秒切分，导致：
- 在句子中间切断
- 同一段话被分成多段，搜索重复素材
- 不考虑语义和主题变化

**解决方案**: 实现 `_nlp_segment_subtitles()` 方法

**核心逻辑**:
```python
def _nlp_segment_subtitles(self, subtitles, data):
    """使用NLP规则智能分段字幕"""

    # 配置参数
    min_duration = 3.0  # 最小镜头时长
    max_duration = 10.0  # 最大镜头时长

    # 分段条件：
    # 1. 句子结束（。！？.!?;；）且 >= 最小时长
    # 2. 主题变化（关键词重叠度<30%）且 >= 最小时长
    # 3. 超过最大时长，强制分段
```

**新增辅助方法**:
- `_is_sentence_end()`: 检测句子结束标点
- `_is_topic_change()`: 检测主题变化（关键词重叠度）
- `_generate_theme()`: 根据关键词生成主题描述

**效果对比**:

**优化前**:
```
字幕: "今天我们来介绍人工智能的发展历史，从1950年代开始" (15秒)
分段:
  - 0-6s: "今天我们来介绍人工智能的发展历史，从1950年代开始"
  - 6-12s: "今天我们来介绍人工智能的发展历史，从1950年代开始"
  - 12-15s: "今天我们来介绍人工智能的发展历史，从1950年代开始"
问题: 3个镜头搜索相同关键词，重复素材
```

**优化后**:
```
字幕1: "今天我们来介绍人工智能的发展历史。" (5秒)
字幕2: "从1950年代开始，科学家们就开始研究这个领域。" (6秒)
字幕3: "现在AI已经应用到各行各业。" (4秒)

分段:
  - 镜头1 (0-5s): "今天我们来介绍人工智能的发展历史。"
    关键词: [人工智能, 发展, 历史]
  - 镜头2 (5-11s): "从1950年代开始，科学家们就开始研究这个领域。"
    关键词: [科学家, 研究, 领域]
  - 镜头3 (11-15s): "现在AI已经应用到各行各业。"
    关键词: [AI, 应用, 行业]

优势: 3个镜头搜索不同关键词，素材多样化
```

### 2.2 多样化素材搜索 ✅

**问题**: 原来虽然搜索多个Provider，但：
- 没有保证素材多样性
- 可能都是相似风格
- 用户缺少对比选择

**解决方案**: 优化 `_search_candidates_for_shot()` 方法

**核心改进**:

1. **为每个查询词单独搜索**
```python

for query_index, query in enumerate(queries[:3]):
    # 每个查询词搜索素材
    # 至少保留1个最佳素材
```

2. **确保素材多样性**
```python
def _ensure_diversity(candidates):
    """确保不同Provider、不同查询词"""
    # 优先选择：
    # - 不同Provider的素材
    # - 不同查询词的素材
    # - 保证至少1-3个不同风格
```

**效果对比**:

**优化前**:

### 2.3 智能评分算法 ✅

**问题**: 原来的评分只考虑时长、分辨率、Provider，不考虑语义匹配

**解决方案**: 优化 `_score_candidate()` 方法

**新增评分维度**:

| 维度 | 分值 | 说明 |
|-----|------|------|
| 时长匹配度 | 0-25分 | 素材时长 >= 镜头时长得满分 |
| 分辨率质量 | 0-20分 | 1920x1080得满分 |
| 横竖屏匹配 | 0-10分 | 横屏视频得分 |
| Provider优先级 | 0-10分 | Mazwai(9分) > Videvo(7分) |
| **关键词匹配度** | **0-15分** | ✨新增：检查关键词在URL中出现 |
